# 中文轨风格规范：V2EX 分享创造 / 掘金

> 2026-08-29 从 V2EX 分享创造节点高回复帖实证提炼（4 篇正文 + 10 标题库，见 `corpus/`）。
> 优先级：本文规则 > 语料范文 > 通用写作直觉。掘金版可稍长稍正式（技术长文接受度高），V2EX 版严格照此。

## 硬规律（实证，违反=社区不适）

1. **篇幅克制**：好帖 300-600 字讲完，技术深的可到 2000 字。绝不注水——V2EX 读者对营销腔和字数膨胀极其敏感。
2. **开头从「自己遇到的具体问题」起手**：一句一句摆场景，可以用一个超短句收（如「烦了。」独立成段）。禁止宏大叙事开头（「在当今 AI 快速发展的时代」直接毙）。
3. **轻结构**：可以有少量小标题，甚至带括号骚话（「技术栈（V2EX 应该更想看这段）」——这是社区默契信号，表明你懂这里的人想看什么）。不搞正式报告结构，不做 bullet 轰炸（≤1 组，≤4 项）。
4. **预判读者关注点**：技术栈、定价/开源协议、为什么不用现成的——主动讲，「讲清楚，不玩虚的」。
5. **链接直接放正文**：在线地址、开源仓库、npm 命令，不遮掩不铺垫。
6. **结尾轻互动**：「感兴趣的朋友可以留言」「欢迎大家体验和提建议」——一句就够。禁止求赞求转发性话术。
7. **零 emoji 堆砌、零感叹号轰炸、零营销黑话**（赋能/闭环/极致体验/颠覆）。

## 语气标定

- 口语，逗号多，有停顿感。句子长短交替。
- 自嘲轻量（「哈哈哈哈～～」量级就到头，不要「不是哥们」「尼玛」这种重口——那是公众号人格，V2EX 会觉得浮夸）。
- 敢下判断但不居高临下：「我自己用下来」「说实话」好过「这标志着」「这无疑是」。
- 技术名词给全称：说 Claude Code / DeepSeek / Next.js 16，不说「AI 工具」「某个模型」。

## 标题句式（从标题库提炼）

- 「把 X 放进了 Y」（把股票行情放进了 MacBook 刘海里）
- 「做了一个叫 X 的…」/「开源了一个 X」
- 「苦于没有好用的 X，自己做了一个」
- 「折腾几个月做了个 X，顺便聊聊 Y 踩的坑」（长文向）

共性：第一人称动作 + 具体成果，克制不自夸，允许一个小自嘲。

## few-shot 使用法

起草 prompt 里放 `corpus/stock-island-macapp.md`（400 字标准样本）+ `corpus/fluxdream-ai-edit.md` 节选（长文样本，含骚话括号和定价透明写法）。明确告诉 kimi：学结构和语气，**不要抄内容**。

## 已知失败模式（实测记录）

- 公众号长文风直接套 V2EX → 文风过重 + 为凑长篇幅编造一手经历（2026-08-29 稿 A 实测，两处越界）→ 事实纪律走素材底座，风格走本文
- 情绪标点（。。。/？？？/= =）在 V2EX 慎用——那是重社交平台人格，这里最多一个「～」
