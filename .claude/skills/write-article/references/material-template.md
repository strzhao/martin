# material.md 素材底座模板

> 复制此模板到工作目录填写。防编造机制：起草模型只准用这里的素材，写不到的就留白 `[待补：用户填]`。
>
> **2026-08-31 升级**：底座分两层——**事实层**（数字/命令/链接，防编造）+ **叙事层**（时间线/转折/情绪，防教程体）。只有事实层，模型只能按「合理结构」编出教程体大纲（掘金稿被毙的根因）；叙事层才是「这文章是这个人写的」的来源。

```
# 素材底座 · <选题名> · <日期>

## 叙事层（文章的骨架来自这里，不来自大纲模板）

### 时间线（必填，作者口述为准）
- 起点：什么时候、什么场景下开始觉得这件事非做不可？[用户口述]
- 第一个动作：先做了什么？当时的想法是什么？[用户口述]
- 转折/意外：做着做着发现了什么没想到的？[用户口述]
- 现在：今天它在你的日常里是什么形态？[可实证：会话/日志/截图]
- 情绪锚点：哪个瞬间有真实情绪（烦/爽/懵/意外）？[用户口述]

### 踩坑记录（证据的主力形态）
- 坑1：当时的现象 → 为什么难 → 最后怎么解 [用户口述/会话记录]
- 坑2：……

### 诚实折扣（必配 1-2 条）
- 真实局限：……（用户确认过的）

## 事实层（全部真实，标注来源）

### 产品/主题事实
- <事实条目>（来源：gh repo view / commit <hash> / 实测命令 / 用户口述 <日期>）
- 在线地址 / 开源仓库：
- 核心体验（真实动线，逐句核对过）：

### 真实数据与实证产出
- <star/fork/traffic>（来源：gh api @ 日期）
- **真实产出原文**（可直接引用的 agent 输出/简报/日志，逐字复制）：
- 隐私过滤：哪些真实内容不能进文章（工作私密/生活记录），明确列出

### 链接与命令（实测可跑）
- <命令>（实测输出：<摘要>）

## 互动口径
- 希望读者做什么：体验/提建议/贡献

## 配图计划
- [截图：…] 来源（哪次会话/哪个界面，能否复现截取）
- [截图：…]
```

## 采集协议（填底座前过一遍）

**叙事层采集（先做这个）**：
- [ ] 用户口述过时间线了（三五句话也行，不够就追问「然后呢？发现什么？」）
- [ ] 坑是从真实经历里挖的，不是从功能列表反推的
- [ ] 情绪锚点有真人原话（「烦了」「挺爽的」），不是概括
- [ ] 若用户不在场：从历史会话/issue/commit message 里挖真实时间线，挖不到就**把叙事层标为缺口，宁可延期不起草**

**事实层采集**：
- [ ] gh api 拉最新数据
- [ ] 命令实测一遍（装得上、跑得通才写）
- [ ] 真实产出原文逐字拿到（截图来源明确、隐私过滤完成）
- [ ] 链接全部 curl 过（200 才放）
