# 外部作者与视频研究验证记录

验证日期：2026-11-27。材料均固定在同一历史时点，未改生产持仓、cron、推送或看护状态。

## 发现阶段 A/B

围绕“存储产业变化是否改变兆易创新等 Q4 的研究口径”做了两组独立研究，再匿名交给未参与研究的复核者。

1. **A（现有工作流＋原始来源清单） vs B（额外提供老张、坤元视频）**：B 中等幅度胜出，主要是兆易半年报经营证据、预测时态和验证时间轴更完整；但复核未发现视频本身提供了可入模的一手新增事实，因此只支持按需找线索。
2. **A0（无视频、无预设库存报道，只用现有工具自主发现） vs B**：A0 胜出。它通过金融桥找到了更近的兆易投资者关系记录、江波龙与澜起正式三季报，公司业务映射更直接。视频有补充价值，但不是获得高价值信息的必要通道。

两轮复核的共同结论是：**公司正式披露回答公司问题，产业原文回答行业预测；视频只在有证据缺口时用于定位原始资料，未经回查的字幕数字不得进入事实层。**

## 最小回归场景

`external-analysis.json` 覆盖三个场景：

- `storage-disclosure-first`：拒绝把企业级 NAND、HBM 与兆易业务混同，区分现货、合约价和预测；Sonnet、Haiku 与实际 hkstock Hermes profile 均通过。
- `pce-conflict`：识别 10 月核心 PCE 同比 3.3% 与三季度年化季率 2.5%，不采用冲突字幕；Sonnet 通过。
- `compute-model`：正确复算 1214÷35%≈3468.57 亿美元及五年 CAGR 约 44.64%，只作为条件情景；首轮对敏感性展开不足，补充“至少检查一个关键假设”后，复测能量化费用、费用率和收入基数变化的影响，通过。

## 环境与使用边界

评测在隔离 profile 中执行，未向真实 profile 部署。生产按热重载使用，不要求额外部署；本 PR 不携带其他历史工作里的部署脚本。

生产使用仍须保持：先公司披露与产业原文，后按需视频；没有新增原始资料、业务映射或可复算模型就停止，不新增 cron 或默认推送。
